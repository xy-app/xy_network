# 端口可用性检测 (PortCheck)

## 1. 功能概述
`PortCheck` 算子通过执行非阻塞底层 TCP 三次握手，极速探测指定目标 IP/主机上的特定服务端口是否已开启对外监听，并精准测量连接建立往返耗时（RTT）。

## 2. 核心特性与工业痛点解决
- **轻量级零开销探测**：仅完成 TCP 握手确认端口开放后立即优雅断开，不在远端服务留下僵尸连接，耗时仅需数毫秒到数十毫秒。
- **服务就绪轮询等待利器**：在自动化启动后台数据库、Docker 容器、微服务或本地进程后，使用 `PortCheck` 确认服务完全启动就绪，取代粗暴的“固定休眠 10 秒”，大幅缩短自动化流程总耗时。
- **支持毫秒级超时**：支持灵活设定超时秒数，遇到防火墙静默丢包时迅速返回，不拖慢整体流程。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `host` | `String` | `"127.0.0.1"` | 目标主机 IP 地址或域名 |
| `port` | `Number` | `80` | 需要探测的目标网络端口号 (1 - 65535) |
| `timeout` | `Number` | `5` | 连接探测超时时间（秒） |

## 5. 输出变量与上下文
- **返回值**：检测结果 JSON 字符串：
  ```json
  {
    "host": "127.0.0.1",
    "port": 80,
    "is_open": true,
    "latency_ms": 3
  }
  ```
- **上下文变量**：
  - `port_is_open`：端口是否处于开放监听状态（布尔值）。
  - `port_latency_ms`：握手连接耗时（毫秒）。

## 6. 典型应用场景
- **服务就绪状态主动探测**：启动本地开发服务器、模拟器或数据库后，循环探测其对外端口直至确认开启。
- **内网安全端口排查**：检测指定工控机或服务器关键端口（如 22, 3389, 3306, 8080）是否对外暴露。
