# 端口可用性检测 (PortCheck)

探测目标主机指定网络端口的连通开放状态与握手耗时。

## 运行参数

* **目标主机 (IP或域名) (`host`)**
  * 类型: `string`
  * 默认值: `"127.0.0.1"`
  * 描述: 待测试的目标服务器 IP 地址或域名。
* **网络端口号 (`port`)**
  * 类型: `number`
  * 默认值: `80`
  * 描述: 待检测的通信服务端口。
* **探测超时时间 (毫秒) (`timeout_ms`)**
  * 类型: `number`
  * 默认值: `1000`
  * 描述: 等待握手响应的最大毫秒数。

## 输出

* 类型: `string`
* 描述: 端口开放状态 (Open/Closed) 及延迟毫秒。

## 使用示例

```json
{
  "tag": "PortCheck",
  "host": "192.168.1.1",
  "port": 80,
  "timeout_ms": 1000
}
```
