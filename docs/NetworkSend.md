# 网络发送 (NetworkSend)

## 1. 功能概述
`NetworkSend` 算子通过已建立连接的 TCP 或 UDP 套接字，向对端主机发送纯文本字符串（`Text`）或十六进制（`Hex`）工业二进制报文，并可选自动追加换行符。

## 2. 核心特性与工业痛点解决
- **Text / Hex 原生双编码支持**：工控调试时可直接输入 `"01 03 00 00 00 02 C4 0B"` 形式的 Hex 字符串，算子自动校验并转为 Raw 字节流发送，无需手动进行二进制格式转换。
- **自动尾部定界追加 (append_crlf)**：针对 SCPI 仪器或行协议设备，开启后自动追加 `\r\n`，保证指令正确触达。
- **线程安全的高并发保护**：底层基于并发保护互斥锁，多任务环境下不会出现报文帧交错交织损坏。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `socket` | `MixedType` | `"default_socket"` | 已连接的套接字句柄名称 |
| `value` | `MixedType` | `""` | 待发送的数据内容（文本或十六进制字符串） |
| `data_mode` | `MixedType` | `"Text"` | 数据发送模式：`"Text"` 或 `"Hex"` |
| `append_crlf` | `MixedType` | `0` | 是否在数据末尾自动追加 `\r\n`（`1` 为是，`0` 为否） |

## 5. 输出变量与上下文
- **返回值**：发送状态结果。
- **上下文变量**：
  - `network_last_sent_bytes`：本次成功发送的字节数。

## 6. 典型应用场景
- **PLC 寄存器读取/写入指令下发**：下发 Modbus RTU-over-TCP 或以太网二进制控制帧。
- **串口网关设备控制**：向网络继电器或 LED 显示屏发送控制指令。
