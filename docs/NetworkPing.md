# 网络连通性探测 (NetworkPing)

跨平台探测目标主机的网络往返延迟 (RTT) 与连通可用性。

## 运行参数

* **探测目标主机 (IP或域名) (`host`)**
  * 类型: `string`
  * 默认值: `"127.0.0.1"`
  * 描述: 待测试连通性的目标主机名或 IP 地址。
* **探测超时时间 (毫秒) (`timeout_ms`)**
  * 类型: `number`
  * 默认值: `2000`
  * 描述: 每次探测等待回显的最长毫秒时间。

## 输出

* 类型: `string`
* 描述: 探测往返耗时（如 `25ms`）或超时失败提示。

## 使用示例

```json
{
  "tag": "NetworkPing",
  "host": "www.baidu.com",
  "timeout_ms": 2000
}
```
