# 网络连通性探测 (NetworkPing)

## 1. 功能概述
`NetworkPing` 算子用于探测目标主机或 IP 的网络连通性、往返时延（RTT）及丢包率。基于跨平台原生系统探测机制实现，**完全不需要管理员/Root 高权限**，标准普通用户权限即可高速执行。

## 2. 核心特性与工业痛点解决
- **零管理员权限痛点**：传统 RAW Socket ICMP Ping 在 Windows 和 Linux 上必须以 Administrator / Root 或特定 cap_net_raw 权限运行，极不适合普通 RPA 桌面环境。`NetworkPing` 通过调用系统标准探测接口，普通权限即可安全运行。
- **多轮采样与时延统计**：支持配置探测轮数（如 `count: 4`），自动统计最小、最大、平均往返耗时（毫秒）以及丢包百分比。
- **流程前置健康自检**：在执行关键大批量网络交互前，前置探测目标网络是否通畅，避免大批任务直接超时报错。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `host` | `String` | `"8.8.8.8"` | 探测的目标域名或 IPv4/IPv6 地址 |
| `count` | `Number` | `4` | 探测报文发送次数（轮数） |
| `timeout` | `Number` | `2` | 单次探测超时时间（秒） |

## 5. 输出变量与上下文
- **返回值**：探测结果详细统计 JSON 字符串：
  ```json
  {
    "host": "8.8.8.8",
    "success": true,
    "transmitted": 4,
    "received": 4,
    "loss_rate": "0%",
    "avg_rtt_ms": 15
  }
  ```
- **上下文变量**：
  - `ping_success`：是否可达（布尔值）。
  - `ping_avg_rtt_ms`：平均往返时延毫秒数。
  - `ping_loss_rate`：丢包率（如 `"0%"`）。

## 6. 典型应用场景
- **RPA 网络健康前置巡检**：早上上班或大促活动前，批量 Ping 内部服务器，生成网络可用性巡检报告。
- **主备线路连通性自适应切换**：通过 Ping 探测主网络延迟，若丢包率超过阈值则自动切换到备用代理或专线。
