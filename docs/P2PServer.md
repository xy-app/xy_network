# P2P 信令与中继服务 (P2PServer)

## 1. 功能概述
`P2PServer` 算子用于在本地或云端服务器启动公共 P2P 信令发现、WebRTC 握手协助与端到端加密流量中继转发中心，并可选集成轻量级静态 Web 资源下载站点。

## 2. 核心特性与工业痛点解决
- **全异步高并发信令调度**：采用 Tokio 与 Axum 架构，单实例可承载成千上万个 P2P 节点的并发信令交换与房间状态广播。
- **智能流量中继 (enable_relay)**：为完全无法穿透 NAT 的对称受限节点提供加密流量兜底中继，避免任务失败。
- **可选嵌入式 Web 分发页面**：配置 `optional_root_folder` 时自动开启 HTTP 静态文件站点，支持浏览器直接在线预览和下载。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (使用普通非特权端口无需管理员权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `bind_address` | `String` | `"0.0.0.0:8080"` | 信令及中继服务绑定的本地网络接口与端口 |
| `enable_relay` | `Bool` | `true` | 是否为穿透失败的节点提供加密数据中继通道 |
| `optional_root_folder` | `DirectoryPicker` | `""` | 可选的静态 Web 资源根目录路径 |

## 5. 输出变量与上下文
- **返回值**：服务启动状态与监听地址（布尔值/JSON）。
- **上下文变量**：
  - `p2p_server_bind_address`：绑定的服务监听地址。

## 6. 典型应用场景
- **私有化 P2P 穿透中继基础设施**：在企业专网内独立部署自建信令服务器，保证所有信令与中继数据完全在局域网内流转。
- **临时组网数据分发中心**：在会议现场或离线封闭网络中快速搭建一台临时分发服务器。
