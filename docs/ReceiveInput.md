# 接收远程输入事件 (ReceiveInput)

## 1. 功能概述
`ReceiveInput` 算子通过网络套接字监听来自远端控制端设备的输入指令（如鼠标移动、点击、按键等），解析指令并应用坐标校准偏移后，在本地触发模拟操作，并支持安全 Token 身份校验。

## 2. 核心特性与工业痛点解决
- **多机协同与远程受控自动化**：在分布式多台物理机/虚拟机集群中，主控机下发操作指令，多台受控机同步执行。
- **Token 身份安全防护**：配置 `auth_token` 后，严格阻断未经授权的网络报文，防止局域网内任意恶意指令注入。
- **动态坐标偏移校准 (offset_pos)**：针对多显示器分辨率不同或窗口位置差异，支持设置 `dx,dy` 偏移量。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `host_address` | `MixedType` | `"0.0.0.0:9988"` | 本地监听绑定的网络地址与端口 |
| `offset_pos` | `MixedType` | `"0,0"` | 坐标偏移校准量（格式 `"x,y"`） |
| `protocol` | `MixedType` | `"TCP"` | 传输协议：`"TCP"` 或 `"UDP"` |
| `auth_token` | `MixedType` | `""` | 可选的安全鉴权 Token 口令 |
| `timeout_secs` | `MixedType` | `60` | 等待接收远程指令的超时时间（秒） |

## 5. 输出变量与上下文
- **返回值**：成功接收并执行的指令描述。

## 6. 典型应用场景
- **分布式自动化集群协同**：中控平台统一下发批量录入指令至各个物理工位。
- **无人巡检机远程遥控**：通过局域网接收操作员中继指令。
