# 域名查询 (DomainQuery)

## 1. 功能概述
`DomainQuery` 算子用于调用操作系统原生网络解析栈，对指定域名（`p_node_name`）或网络服务名称/端口（`p_service_name`）进行 DNS 查询与套接字地址解析，输出目标主机的 IPv4 / IPv6 地址列表及标准 Socket 描述。

## 2. 核心特性与工业痛点解决
- **真实原生 DNS 解析**：基于底层操作系统标准解析器，彻底替代旧版仅打印日志的桩代码，具备真实的域名解析能力。
- **双栈地址支持**：自动解析并输出 IPv4 及 IPv6 地址，便于工业网络环境中的双栈网络诊断与动态 IP 追踪。
- **服务名称与端口自动匹配**：支持输入标准服务名（如 `"http"`、`"https"`、`"ssh"`）自动推断端口号，也支持直接输入数字端口（`"80"`、`"443"`）。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `p_node_name` | `String` | `"localhost"` | 目标主机名、域名或 IP 字符串（如 `"www.baidu.com"`、`"localhost"`） |
| `p_service_name` | `String` | `"http"` | 网络服务名或端口号（如 `"http"`、`"80"`、`"https"`、`"443"`） |

## 5. 输出变量与上下文
- **返回值**：标准格式 JSON 字符串，汇总解析到的所有套接字地址与 IP 列表：
  ```json
  {
    "query": "www.baidu.com:http",
    "ip_list": ["180.101.50.188", "180.101.50.242"],
    "addresses": ["180.101.50.188:80", "180.101.50.242:80"]
  }
  ```
- **上下文变量**：
  - `dns_resolved_ips`：逗号分隔的已解析 IP 列表字符串。
  - `dns_primary_ip`：首选解析到的 IP 地址。

## 6. 典型应用场景
- **动态域名解析与健康检查**：在连接远端微服务前，探测其域名当前指向的真实服务器 IP。
- **网络诊断与 DNS 劫持排查**：定时检测关键业务域名是否被解析到异常的未知内网地址。
