# P2P 文件分发节点 (P2PHost)

## 1. 功能概述
`P2PHost` 算子作为去中心化 P2P 文件分发的发起方节点，与信令服务器建立长连接并发布本地共享目录（`folder_path`），基于 WebRTC / Direct 穿透技术与远端对等客户端建立点对点数据传输通道，当 NAT 打洞失败时支持自动降级至加密中继转发。

## 2. 核心特性与工业痛点解决
- **内网 NAT 自动打洞穿透**：通过信令服务器协助交换 ICE/SDP 候选者，在复杂双层 NAT 和企业防火墙内网环境下建立高速直连通道。
- **中继降级回退保障 (relay_fallback)**：若双方 NAT 属于对称型（Symmetric NAT）导致打洞失败，自动平滑无缝回退至公共服务器中继模式，确保 100% 成功交付。
- **轻量级房间码配对**：支持自定义房间口令/共享码（`share_code`），配对成功即可自动开始数据交换，无需繁琐的公网 IP 或域名配置。
- **大文件切片极速流式分发**：支持文件分块哈希校验与断点续传，不占用主服务器集中下行带宽。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `folder_path` | `DirectoryPicker` | `""` | 共享给远端对等节点的本地文件夹完整路径 |
| `server_url` | `String` | `"ws://127.0.0.1:8080/ws"` | 公共信令与穿透中继服务器 WebSocket 地址 |
| `share_code` | `String` | `"default"` | 配对提取房间码/口令 |
| `relay_fallback` | `Bool` | `true` | 打洞失败时是否允许自动回退至服务器流量中继 |

## 5. 输出变量与上下文
- **返回值**：P2P 分发节点运行状态结果（布尔值/JSON）。
- **上下文变量**：
  - `p2p_host_share_code`：当前共享房间码。
  - `p2p_host_status`：当前服务状态。

## 6. 典型应用场景
- **跨网段/跨分支机构文件互传**：两台均处于内网无公网 IP 的办公电脑之间快速共享几个 GB 的设计文件。
- **无人值守自动化数据归档**：分支机构测试机向总部服务器自动同步大容量测试日志。
