# WebSocket 接收消息 (WebSocketReceive)

## 1. 功能概述
`WebSocketReceive` 算子通过已建立的 WebSocket 长连接，等待并接收对端推送的单条文本或二进制消息，并在指定超时时间内完成返回。

## 2. 核心特性与工业痛点解决
- **超时保护与阻塞控制**：支持设置 `timeout` 秒数，在指定时间内未收到数据安全返回超时状态，避免工作流永久卡死。
- **协议帧智能识别与自动转换**：能够自动解析 Text 文本帧和 Binary 二进制帧，二进制内容自动转为标准十六进制 Hex 字符串返回，便于后续处理。
- **自动上下文推导**：未指定 `connection_id` 时自动沿用当前工作流最近的 WebSocket 连接。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `connection_id` | `String` | `""` | WebSocket 连接标识符（留空自动使用当前上下文连接） |
| `timeout` | `Number` | `30` | 等待接收消息的最大超时时间（秒） |

## 5. 输出变量与上下文
- **返回值**：接收结果 JSON 字符串：
  ```json
  {
    "status": "received",
    "connection_id": "ws_127.0.0.1:8080",
    "type": "Text",
    "message": "{\"topic\": \"quote\", \"price\": 102.5}"
  }
  ```
- **上下文变量**：
  - `ws_received_message`：接收到的消息正文字符串。
  - `ws_message_type`：消息类型 (`"Text"` 或 `"Binary"`)。

## 6. 典型应用场景
- **长连接下发通知抓取**：等待服务端下发结算完成、订单处理成功或状态变更推送。
- **即时响应与多轮交互**：配合 `WebSocketSend` 组成连续的“发送-接收”双工交互回路。
