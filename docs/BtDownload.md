# BT/种子下载 (BtDownload)

## 1. 功能概述
`BtDownload` 算子基于纯 Rust `librqbit` v9 高性能 BitTorrent 引擎，支持通过 `.torrent` 种子文件或 `magnet:?xt=...` 磁力链接高速下载网络或局域网中的共享资源，具备自动 DHT 寻轨与对等节点穿透加速能力。

## 2. 核心特性与工业痛点解决
- **种子文件与磁力链接双模驱动**：无缝支持传入本地 `.torrent` 文件或标准 Magnet 磁力链接 URI。
- **纯 Rust 工业级稳定引擎**：基于 `librqbit` v9，杜绝了传统 C++ libtorrent 绑定繁复的动态链接库缺失、版本冲突或内存泄漏风险。
- **自动断点校验与智能恢复**：支持中断后再次运行自动比对已存在的数据块校验哈希，只下载缺失切片。
- **去中心化无服务器依赖**：内置 DHT 与对等节点发现能力，适合在无固定中心下载服务器的网络环境中高效拉取资源。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `file` | `FilePicker` | `""` | 本地 `.torrent` 文件路径或 `magnet:?xt=...` 磁力链接 |
| `save_path` | `DirectoryPicker` | `""` | 资源文件保存的目标目录路径 |

## 5. 输出变量与上下文
- **返回值**：下载结果 JSON 格式字符串：
  ```json
  {
    "status": "completed",
    "torrent": "demo.torrent",
    "output_dir": "C:/Downloads"
  }
  ```
- **上下文变量**：
  - `bt_download_status`：下载状态（`"completed"`）。
  - `bt_download_output_dir`：实际保存目录绝对路径。

## 6. 典型应用场景
- **分布式大文件同步**：从企业内部 P2P 分发集群中同步大体积镜像包或离线升级固件。
- **离线资源批量拉取**：通过磁力链接或种子文件批量拉取开源公开数据集与多媒体资源。
