# BT/种子做种分发 (BtSeed)

## 1. 功能概述
`BtSeed` 算子基于纯 Rust 架构的 `librqbit` v9 高性能 BitTorrent 引擎，用于将本地资源文件作为 Peer 节点向 P2P 网络持续做种共享。支持指定单个 `.torrent` 种子文件，或**动态监听种子文件夹**（当在该文件夹中新放入种子文件时自动开始做种，删除种子文件时自动停止做种），无需重新扫描哈希。

## 2. 核心特性与工业痛点解决
- **纯 Rust 工业级引擎**：采用 `librqbit`，零 C++ 外部依赖、无内存泄漏风险，占用极低内存常驻后台服务。
- **动态种子监听模式 (Watch Folder)**：在分布式节点或工业局域网分发场景中，用户只需将生成的 `.torrent` 文件丢入监听目录，算子自动感知并加入 Peer 网络对外分发；文件移除后自动安全停止做种并释放网络连接。
- **本地资源数据关联**：精准绑定实际资源数据存放的 `resource_folder`，跳过无谓的二次数据拷贝。
- **可控做种生命周期**：支持设定限时做种（如 `seed_duration: 3600` 秒）或长期驻留做种（`seed_duration: 0`），完美契合自动化流水线发布环节。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `torrent_path` | `FilePicker` | `""` | 单个种子文件路径（`.torrent`），与监听文件夹二选一 |
| `watch_folder` | `DirectoryPicker` | `""` | 种子监听文件夹路径，自动感知 `.torrent` 文件的增删并热启停做种 |
| `resource_folder` | `DirectoryPicker` | `""` | 实际本地资源数据目录，做种客户端据此定位并上传数据切片 |
| `port` | `Number` | `4240` | BitTorrent 做种 Peer 监听端口 |
| `seed_duration` | `Number` | `0` | 做种持续时间（秒），`0` 表示无限驻留持续做种 |

## 5. 输出变量与上下文
- **返回值**：标准格式 JSON 字符串，汇总做种任务状态、端口与监听信息：
  ```json
  {
    "status": "seeding",
    "mode": "watch_folder",
    "torrents_count": 3,
    "port": 4240,
    "resource_folder": "C:/Distribution/Releases"
  }
  ```
- **上下文变量**：
  - `bt_seed_status`：当前做种状态（如 `"seeding"`、`"completed"`）。
  - `bt_seed_torrents_count`：当前活跃做种的种子数量。

## 6. 典型应用场景
- **企业内部海量软件包分发**：构建去中心化局域网分发网络，避免单台中心服务器带宽被打满。
- **自动化构建发布制品分发**：CI/CD 流水线完成大体积构建制品（如几 GB 的固件、安装包）后自动做种分发给数百台测试机。
- **动态种子热分发**：只需将新版本种子文件放入共享目录，分发节点自动开始为新种子做种。
