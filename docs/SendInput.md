# 发送远程输入事件 (SendInput)

## 1. 功能概述
`SendInput` 算子通过网络套接字将本地捕获或工作流编排的鼠标/键盘控制动作封装成安全报文，同步发送至远端受控设备执行，支持配置安全鉴权口令。

## 2. 核心特性与工业痛点解决
- **轻量级跨机输入广播**：无需安装沉重高延迟的 VNC 或 TeamViewer 服务，即可通过原生套接字实现毫秒级事件同步。
- **TCP / UDP 双通道选择**：对丢包敏感的关键录入操作选择 TCP，对高频鼠标轨迹同步选择极低延迟的 UDP。
- **内置安全认证口令**：报文自动打包携带 `auth_token`，确保目标受控端严格只认主控机指令。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (标准用户权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `host_address` | `MixedType` | `"127.0.0.1:9988"` | 远端目标受控设备的网络地址与端口 |
| `offset_pos` | `MixedType` | `"0,0"` | 坐标偏移补偿（格式 `"x,y"`） |
| `input_data` | `MixedType` | `"click:left"` | 待发送的输入动作数据内容 |
| `protocol` | `MixedType` | `"TCP"` | 传输协议：`"TCP"` 或 `"UDP"` |
| `auth_token` | `MixedType` | `""` | 安全认证令牌 |

## 5. 输出变量与上下文
- **返回值**：发送状态结果。

## 6. 典型应用场景
- **双机热备/主从机器同步操作**：主控机操作时自动将击键同步至副机。
- **自动化测试远程触发**：向待测目标板卡或受控终端下发触发按键。
