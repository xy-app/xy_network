# 网络监听 (NetworkListen)

## 1. 功能概述
`NetworkListen` 算子在指定的本地网络接口和端口上绑定并监听入站 TCP 或 UDP 连接，并在有远程客户端成功接入时将其登记到全局套接字池（`SOCKET_POOL`），供后续收发算子直接使用。

## 2. 核心特性与工业痛点解决
- **被动等待工业设备连接**：在许多工控现场，工控机或产线终端作为服务端等待 PLC 或测试仪器主动连接建立握手通道。
- **超时保护退出机制**：可设定等待连接超时秒数，避免无客户端接入时流程陷入无限死等。
- **自动注册全局对象池**：客户端接入后生成的 Stream 自动注入连接池，与主动连接模式享有完全统一的生命周期与操作 API。

## 3. 平台支持与权限
- **支持平台**：`Windows` / `Linux` / `macOS` (跨平台通用)
- **管理员权限**：`否` (使用普通端口无需管理员权限)

## 4. 参数说明

| 属性名称 | 参数类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `socket_address` | `String` | `"0.0.0.0:8080"` | 本地绑定的网络接口和监听端口 (如 `"0.0.0.0:8080"`) |
| `protocol` | `String` | `"TCP"` | 传输层协议：`"TCP"` 或 `"UDP"` |
| `handle_name` | `MixedType` | `"default_socket"` | 接入成功后注册的套接字句柄标识 |
| `timeout_secs` | `Number` | `60` | 等待客户端接入的最大超时时间（秒） |

## 5. 输出变量与上下文
- **返回值**：监听接入结果 JSON 字符串：
  ```json
  {
    "status": "accepted",
    "handle": "default_socket",
    "protocol": "TCP",
    "client_addr": "192.168.1.50:52410"
  }
  ```
- **上下文变量**：
  - `network_accepted_client`：接入的远程客户端 IP:Port。
  - `network_connected_socket`：句柄名称。

## 6. 典型应用场景
- **工控产线数据采集服务端**：等待各工位检测仪器完成测试后主动上报结果。
- **局域网设备自动发现配对**：监听特定端口等待客户端上线广播打招呼。
